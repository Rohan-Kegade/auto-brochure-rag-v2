# PDF Loader Evaluation

## Objective

Evaluate different PDF loaders for extracting content from
car brochure PDFs.

## Candidates

- PyPDFLoader
- PyMuPDF
- PDFPlumber
- PDFMuse

## Evaluation Criteria

1. Text extraction
2. Table extraction
3. Page metadata
4. Layout preservation
5. Processing time
